# 🎵 Music Streaming App

## 📌 About the Project

The **Music Streaming App** is a college team project developed using Java Programming Language. The main objective of this project is to provide a simple and user-friendly music application where users can explore and play music through an easy-to-use interface.

This project was developed as part of our college academic work to gain practical experience in Java programming, application development, and teamwork.

## ✨ Features

- 🎶 Music playback functionality
- 🎧 User-friendly interface
- ▶️ Play and control music
- ⏸️ Pause and resume music
- 📂 Organized music management
- 💻 Desktop application interface
- 📩 Upload song
- 🎬 Create Playlists



## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI:** Java Swing
- **IDE:** Visual Studio Code
- **JDK:** Java Development Kit

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
  https://github.com/shiv21s/My-Music/blob/main/MyMusicApp.java
   ```

2. Open the project folder in Visual Studio Code.

3. Make sure Java JDK is installed on your computer.

4. Install the required Java extensions in VS Code.

5. Run the main Java file to launch the application.
